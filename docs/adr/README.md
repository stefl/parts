# Decision records

Decisions about the Parts pattern itself, with their reasons, one file each. A record is never rewritten: a change is a new record plus a dated `## Amendment` section appended to the old one.

Numbers come from a register (`fibers mint ADR "<title>"`), so two sessions never take the same one. A ruled record is also recorded on the board with `fibers decide`, and its status block names the `D-<n>`.
